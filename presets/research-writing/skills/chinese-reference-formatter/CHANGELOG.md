# Changelog

## 1.1.1

- 忽略空作者及空占位，避免一条记录中断整个批次；占位不再影响作者截断和引用键。
- 保留 `T.N.` 等连续首字母、小写姓氏前缀以及 `Jr.` 等姓名后缀；中文条目和 BibTeX 使用一致的姓名信息。
- 章节的 `container` 书名同时用于中文条目与 BibTeX；报告的 `publisher` 在缺少 `institution` 时补充 BibTeX 机构字段，明确字段优先。
- 增加对应的批量输出、姓名和字段映射回归测试。
- 更新 CI 和 Release 的官方 Actions 组件，消除 Node.js 20 运行时弃用提示。

含空作者占位或特殊姓名的引用键可能被修正。更新已有 `.bib` 时保留正文正在使用的键。

## 1.1.0

- 修正 ICLR 示例：按会议论文引用，移除混入会议记录的 arXiv DOI。
- 保留来源题名的大小写；BibTeX 保护题名大小写、转义文本特殊字符并保留机构作者。
- 修正标准文献的标志位置；在线载体保留访问日期和 URL；会议记录保留出版地、出版者及 DOI。
- 引用键加入完整题名、作者、年份和 DOI 的摘要；同一批次重复键追加后缀。
- 学位论文区分硕士与博士；学位未知时使用 `@misc`，不推断博士学位。
- 保留歧义记录的来源、更多 BibTeX 字段和显式文献语言；非法输入返回清晰错误。
- 增加可运行示例、回归测试、GitHub Actions、可重复构建的 ZIP，以及按版本标签生成 Release 草稿的工作流。
- 明确通用格式与 GB/T 7714 具体版本的支持边界，完善平台安装与分发说明。

### 升级说明

自动生成的 BibTeX 键与 1.0.0 不同。替换已有 `.bib` 条目时，需要同步更新正文的引用键；也可以保留项目原有键，只更新条目内容。

本版本提供通用顺序编码格式，不声明完整符合 GB/T 7714—2015 或 GB/T 7714—2025。指定版本或投稿细则需要单独核对。
